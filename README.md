# Do_not_Press_the_Button
A game where you press a button and go to a maze, running from a monster to gain coins for shop items

## How this was made
it was made by godot engine using GDScript. animation and assets was taken from licenced and free models on the internet.

## Why I made this
I love making games, so why not make a game with a new features I've never built before. I built a 3d game before and it's in my github account. it's 3d shooter, but this is a horror game with holding, moving, rotation mechanics.

## Things implemented

1. player movements and camera
2. simple room for button and shop
3. button that transfare you to the maze
4. shop mechanics and buying
5. navigation region
6. monster
7. a horror environment (lights)
8. coins
